# Kali Cartomancia — Landing Page

Landing Page mobile-first desenvolvida para a Kali Cartomancia,
com foco em divulgação através do Instagram e conversão de visitantes
em agendamentos pelo WhatsApp.

## Funcionalidades

- Design otimizado para dispositivos móveis
- Apresentação dos serviços de cartomancia
- Seleção do tipo de tiragem
- Formulário de agendamento
- Geração automática de mensagem para o WhatsApp
- Depoimentos com animação
- Layout responsivo
- Animações e efeitos visuais
- SEO básico e metatags para compartilhamento

## Tecnologias

- HTML5
- CSS3
- JavaScript

> Todo o projeto foi desenvolvido em um único arquivo HTML,
> com CSS e JavaScript incorporados.

## Objetivo

Criar uma página de divulgação simples, elegante e otimizada para
Instagram, permitindo que o visitante conheça os serviços e entre
em contato diretamente pelo WhatsApp.
